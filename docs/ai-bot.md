# 🤖 AI Ассистент MAX Bot API (`cmd/ai-bot`)

Высокопроизводительный мультимодальный AI-бот для **MAX Messenger**, подключенный к интеллектуальному шлюзу **Go Model API (GMA)** ([`https://gma.littfed.ru`](https://gma.littfed.ru)).

---

## ⚡ Ключевые возможности

1. **💬 Умный диалоговый чат-бот (LLM):**
   - Автоматическая маршрутизация запросов через смарт-роутер `@scout` (динамический подбор оптимальной модели без задержек и ошибок 429).
   - Скользящее окно памяти контекста в оперативной памяти (Ring-buffer на 12 сообщений) с автоистечением по таймауту бездействия (30 минут).
   - Команда `/clear` для мгновенной очистки контекста.

2. **👁️ Распознавание и анализ изображений (Vision & OCR):**
   - Автоматический перехват входящих фотографий и картинок из чата MAX.
   - Извлечение прямых ссылок на изображения и передача в мультимодальную модель (`@scout-vision`, `glm-4.6-plus` и др.).
   - Распознавание рукописного и печатного текста, детальное описание графиков, схем и объектов.

3. **🎨 Генерация изображений по текстовому описанию:**
   - Команды `/image <промпт>` и `/draw <промпт>`.
   - Запрос к эндпоинту `/v1/images/generations` шлюза GMA (`flux`, `sdxl`).
   - Прямая загрузка полученного изображения через API загрузок MAX (`/uploads`) и отправка нативным фото-вложением в чат.

4. **⚙️ Интерактивный селектор моделей (`/model`):**
   - Инлайн-клавиатура для быстрого просмотра и переключения моделей чата, распознавания и генерации прямо из мессенджера.
   - Персональное сохранение выбранных моделей для каждого пользователя.

---

## 🚀 Локальный запуск

```bash
# 1. Задайте переменные в .env или передайте флагами:
export MAX_BOT_TOKEN="ваш_токен_из_dev.max.ru"
export GMA_BASE_URL="https://gma.littfed.ru"

# 2. Запуск бота:
go run ./cmd/ai-bot
```

---

## 🐳 Развертывание в Docker и Dokploy

Сервис упакован в минималистичный образ на базе Alpine (`Dockerfile.ai-bot`) со встроенными сертификатами Национального удостоверяющего центра (Минцифры РФ):

```bash
docker build -f Dockerfile.ai-bot -t max-ai-bot .
docker run -d --name max-ai-bot \
  -e MAX_BOT_TOKEN="ваш_токен" \
  -e GMA_BASE_URL="https://gma.littfed.ru" \
  max-ai-bot
```

В **Dokploy** приложение развернуто в проекте `gma.littfed.ru` под именем `max-ai-bot`, автоматически собирается из GitHub-репозитория и перезапускается при обновлениях.
