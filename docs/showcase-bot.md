# 🌟 Флагманский бот-витрина возможностей MAX Bot API (`cmd/showcase-bot`)

Демонстрационный шоурум корпоративного уровня, объединяющий все возможности и сценарии разработки чат-ботов на платформе **MAX Messenger** ([dev.max.ru](https://dev.max.ru/docs/)) в одном интерактивном приложении.

---

## ⚡ Особенности и архитектура

```
                       ┌───────────────────────────────┐
                       │     MAX Messenger Client      │
                       └───────────────┬───────────────┘
                                       │ Long Polling / HTTPS
                                       ▼
                       ┌───────────────────────────────┐
                       │   cmd/showcase-bot/main.go    │
                       └───────┬───────────────┬───────┘
                               │               │
        ┌──────────────────────▼──────┐ ┌──────▼──────────────────────┐
        │        pkg/bot Core         │ │     HTTP Server (:8080)     │
        │ • Router & Middlewares      │ │ • /webapp (HTML5 Mini App)  │
        │ • FSM Session Engine        │ │ • /api/webapp/action (Bridge│
        │ • Under-the-Hood Controller │ │ • /webhook/payments/...     │
        │ • Telemetry Ring Buffer     │ │ • /metrics (OpenMetrics)    │
        └─────────────────────────────┘ └─────────────────────────────┘
```

* **Zero-Config TLS:** автоматическое подключение встроенных корневых сертификатов Национального удостоверяющего центра Минцифры РФ (`//go:embed`).
* **Гибридный формат «Шоурум + Под капотом»:** каждый шаг любого сценария снабжен интерактивной кнопкой **«🔍 Как это устроено?»**, открывающей точные параметры вызова MAX API, FSM-состояния и структуры JSON.
* **Глобальный режим разработчика (`/dev`):** тумблер в главном меню для автоматического добавления технического блока к каждому ответному сообщению бота.
* **Встроенный веб-сервер (порт `:8080`):** автономная раздача адаптивного Mini App (HTML5/CSS), прием заказов через WebBridge и Prometheus метрики.

## 🧭 Пять интерактивных сценариев

### 1. 🛍️ Интернет-магазин & СБП Checkout (`pkg/fsm` + `pkg/payments`)
* **Витрина товаров:** каталог с ценами, описанием и инлайн-кнопками.
* **Многошаговый визард:** пошаговый процесс (выбор товара ➔ адрес доставки/самовывоз ➔ расчет стоимости ➔ подтверждение).
* **Оплата через СБП (НСПК):** генерация динамических платежных ссылок `https://qr.nspk.ru/...` с точностью до копеек и выделением зеленым стилем (`intent: positive`).
* **Sandbox-эмулятор:** инлайн-кнопка «🧪 Симулировать оплату» для мгновенного сквозного тестирования эквайринга без списания реальных денег.

### 2. 📅 Онлайн-запись на услугу (`pkg/fsm` + `pkg/maxbot`)
* **Сетка дат и слотов:** динамическое построение календаря доступного времени визита.
* **Нативный запрос контакта (`request_contact`):** безопасное получение подтвержденного номера телефона клиента из профиля MAX нажатием одной кнопки (с текстовым фоллбеком).
* **Чек бронирования:** генерация карточки брони и напоминания о визите.

### 3. 🧠 Интерактивный Квиз & Reaction Telemetry (`pkg/fsm` + `pkg/telemetry`)
* **Викторина по возможностям платформы:** оценка ответов с моментальными тост-нотификациями.
* **Замер Time-to-Click (TTK):** расчет скорости реакции пользователя с точностью до миллисекунд через сквозную телеметрию.
* **Копирование в буфер обмена (`clipboard`):** нативная системная кнопка `ButtonTypeClipboard`, копирующая результат викторины в буфер обмена пользователя без перехода по ссылкам.

### 4. 📱 Mini App (HTML5 WebView) & WebBridge (`pkg/webapp`)
* **Встроенное веб-приложение:** локальный адаптивный HTML5/JS интерфейс корзины в стиле MAX Messenger, доступный по адресу `http://localhost:8080/webapp`.
* **Запуск через `open_app`:** строгая валидация слага приложения, защищающая от распространенной ошибки MAX `404 LinkPK not found`.
* **WebBridge протокол:** отправка заказа из браузера/webview на HTTP-эндпоинт `/api/webapp/action` с проверкой HMAC-SHA256 подписи `initData` и выводом квитанции в чат бота.

### 5. 🛡️ Комьюнити & Модерация чатов (`pkg/guard`)
* **Интерактивная симуляция в ЛС:** запуск теста входа нового участника с 30-секундным таймером капчи «Я человек» и отклонением кликов посторонних.
* **Симуляция автокика:** демонстрация исключения спам-ботов через `DELETE /chats/{id}/members?user_id=...`.
* **Боевой режим в группах:** перехват события `bot_added` и автоматическая защита сообществ при назначении бота администратором.

## 🚀 Запуск и использование

### Способ 1: С токеном бота (Боевой режим)

```bash
# 1. Задайте токен вашего бота в MAX Messenger:
export MAX_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"   # Linux / macOS
set MAX_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"      # Windows CMD
$env:MAX_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"     # Windows PowerShell

# 2. Запустите бот-витрину:
go run ./cmd/showcase-bot
```

### Способ 2: Без токена (Оффлайн-режим)

Если переменная `MAX_BOT_TOKEN` не задана, бот автоматически запускается в локальном демонстрационном режиме, поднимая HTTP-сервер для WebApp, метрик и симуляторов:

```bash
go run ./cmd/showcase-bot -port 8080
```

После старта будут доступны:
* `http://localhost:8080/webapp` — встроенное Mini App веб-приложение
* `http://localhost:8080/metrics` — Prometheus & OpenMetrics экспортер
* `http://localhost:8080/api/webapp/action` — WebBridge обработчик заказов

| Команда | Описание |
|---|---|
| `/start` | Приветствие и запуск главного интерактивного меню |
| `/menu` | Возврат в главное меню выбора сценариев |
| `/dev` | Переключение режима разработчика («Под капотом») |
| `/stats` | Просмотр метрик и воронки кликов активной сессии |
| `/reset` | Сброс текущего сценария и FSM-состояния сессии |
