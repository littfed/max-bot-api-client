## 1. Обзор требований стандарта `golang-project-layout`

- **Стандартная структура каталогов Go:** Разделение на `cmd/` (исполняемые бинарники), `pkg/` (публичные библиотеки для внешних разработчиков), `internal/` (приватный код проекта);
- **Соответствие имени модуля:** Путь модуля в `go.mod` должен совпадать с каноническим адресом репозитория;
- **Изоляция точек входа:** Логика в `main.go` должна быть минимальной (парсинг флагов/конфигурации, сборка зависимостей, запуск);
- **Организация тестов и примеров:** Размещение юнит-тестов рядом с кодом, выделение `examples/` для обучающих примеров.

## 2. Результаты анализа кодовой базы

### 2.1. Иерархия пакетов
Структура репозитория выстроена по классическому образцу профессиональной библиотеки:
```
max-bot-api-client/
├── certs/            # Встроенные TLS-сертификаты Минцифры РФ
├── cmd/              # Исполняемые сервисы
│   ├── ai-bot/       # Мультимодальный AI-бот (GMA + MAX)
│   ├── showcase-bot/ # Флагманский бот-витрина
│   └── bot-tester/   # CLI-утилита тестирования
├── docs/             # Документация, исследования, ADR
├── examples/         # Пошаговые runnable примеры (01..04)
├── internal/         # Приватный код (сквозные тесты livetest)
├── pkg/              # Публичный SDK для интеграторов
│   ├── bot/          # Движок бота, роутер, middleware
│   ├── fsm/          # Машина состояний диалогов
│   ├── gma/          # Клиент Go Model API и память сессий
│   ├── guard/        # Антиспам и капча
│   ├── maxbot/       # Низкоуровневый REST API клиент
│   ├── payments/     # Платежные шлюзы и СБП
│   ├── telemetry/    # Prometheus телеметрия
│   └── webapp/       # Mini Apps и крипто-мост
└── reports/          # Аудиторские отчеты и логи
```

### 2.2. Соответствие `go.mod`
- Модуль объявлен как `github.com/littfed/max-bot-api-client`, что строго соответствует адресу удаленного репозитория.

### 2.3. Чистота точек входа
- В `cmd/ai-bot/main.go` и `cmd/showcase-bot/main.go` функция `main` отвечает исключительно за считывание переменных окружения, инициализацию зависимостей и прослушивание сигналов операционной системы. Бизнес-логика вынесена в отдельные обработчики.
